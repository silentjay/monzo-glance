# Vendored Monzo-API

This is an unmodified copy of [Monzo-API](https://github.com/petermcd/monzo-api) 1.3.6, the
MIT-licensed Python client used only by `engine/monzoglance/adapter.py` and `login.py`.

It is vendored so the plugin runs on a stock Omarchy Python 3.11+ with no venv or package
install. The upstream `LICENSE` is in this directory. Update this copy as a unit when the
upstream client changes.
